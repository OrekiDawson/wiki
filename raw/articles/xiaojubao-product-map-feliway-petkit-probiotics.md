# 小桔宝家用品产品地图

> 调研日期：2026-06-30  
> 目的：把小桔宝**家里已经买的**和**可能买的**所有"安抚/除味/营养"产品放在一张图上，按"对猫是否安全 + 证据等级"两维评估。  
> 资料来源：Feliway 学术资料 + Petkit 真实成分表 + Beata / Rème / AAFP 5 阶段 + ASPCA 精油清单。

## 1. 家中现有产品（小桔宝家里）

### 1.1 Feliway Classic（F3 扩散器）—— 24h 散

- **成分**：F3 合成版 2% + 异构烷烃 48ml（载体）
- **机制**：猫 VNO → 杏仁核 → HPA 调低警觉（详见 [[concepts/f3-pheromone]]）
- **证据**：强（PLOS One 2023 抓挠 RCT + Mills 2001 喷尿 RCT + Crump 2023 综述）
- **小桔宝用法**：24h 散，48ml 30 天，**7/12 换瓶**

### 1.2 Petkit N60 / N50 净味除臭小方（**小桔宝智能猫厕所里装**）

- **N60 真实成分**（台湾 PETKIT 官网 / 寵物公園）：
  - 去离子水、结冷胶、增溶剂、复合氨基酸、**柿果提取物**、香精、**1,2-己二醇**
- **N50 真实成分**（Shopee 台湾）：
  - 皱波角叉菜、无机盐、增溶剂、复合氨基酸、**柿果提取物**、香精
- **机制**：物理除臭（柿果提取物 = 柿单宁 = **多酚化合物**，吸附氨 / 硫化氢分子）+ 缓慢释放香精
- **关键风险**（ASPCA / Threads 兽医观察）：
  - **柿单宁 = 多酚** → 猫**缺 UGT** → 代谢酚类差 → **慢性积累**风险
  - "对狗安全，对猫有疑虑"（FurLab 兽医观点，2024）
  - 散落在智能猫厕所**内部**，小桔宝**近距离接触** + **可能嗅闻 + 可能舔舐**（猫有舔毛习惯）
  - 不是"扩散到空气"那种扩香，但**密闭空间（猫厕所内部）+ 持续释放** = 风险**集中**

### 1.3 智能猫厕所

- 净味功能（N60 通道） + 自动清洁
- **Oreki 6/30 校准**："不太适应" → **暂时关净味**（已记进 [[queries/f3-for-xiaojubao]]）
- 关掉净味 → 暂停 N60 暴露 → 风险降 0
- 之后再开净味 → 看小桔宝是否有肝酶异常 / 行为变化

## 2. 可能买的产品

### 2.1 α-酪蛋白（Zylkene / 国内仿制）

- 证据：中等（Beata 2007 34 只猫）
- 1-2 月幼猫 RCT = 0
- **不**现在加

### 2.2 L-茶氨酸（Anxitane / 国内仿制）

- 证据：中等（Rème 2018 33 只猫，5 月龄-16 岁）
- **1-2 月幼猫** RCT = 0
- **不**现在加

### 2.3 BL999 益生菌（Purina Calming Care / 国内仿制）

- 证据：较弱（厂商研究，缺透明度）
- 1-2 月幼猫 RCT = 0
- **不**现在加

### 2.4 Royal Canin Calm 处方粮

- 证据：中等（厂商 RCT + 兽医观察）
- **1-2 月幼猫** RCT = 0
- **不**现在换粮
- 幼猫粮有专门配方，**不**用过早切

## 3. 国产仿制警示

- 俏博士 / 京东京造等"费洛蒙扩散器"——**未见 PMC 级别 RCT**
- 用了"仿 F3 配方"——但**没**真按 Ceva 专利 US5709863A 比例 + **没** RCT 验证
- **不**替 Oreki 拍板买哪款，**不**冒险

## 4. 决策表（小桔宝家版）

| 产品 | 是否买/用 | 关键风险 | 证据等级 |
|---|---|---|---|
| **Feliway Classic** | ✅ 在用 | 几乎无 | 强 |
| **Petkit N60/N50** | ⚠️ **暂时关** | 多酚（柿单宁） | 商家宣传 |
| **α-酪蛋白（Zylkene）** | ❌ 不加 | 幼猫 RCT 缺 | 中等 |
| **L-茶氨酸（Anxitane）** | ❌ 不加 | 幼猫 RCT 缺 | 中等 |
| **BL999 益生菌** | ❌ 不加 | 幼猫 RCT 缺 | 较弱 |
| **Royal Canin Calm 粮** | ❌ 不换 | 幼猫 RCT 缺 | 中等 |
| **国产仿制费洛蒙** | ❌ 不买 | 几乎无证据 | 极弱 |
| **精油 / 扩香 / 蜡烛 / 藤条瓶** | ❌ 绝对不用 | 酚类 / 单萜烯 | 强（ASPCA 警示） |

## 5. 关键认知

- **F3 + 不刺激 + 环境管理** = 当前对小桔宝**最稳**的方案
- **6 盏灯 3 颗星持续 1 周+** → 找兽医评估，**不**自己加补剂
- **Petkit N60/N50 是除臭剂 ≠ F3 费洛蒙**，**不**在 F3 地图里
- **多酚类对小桔宝有潜在风险**（缺 UGT），**先**把净味关掉
