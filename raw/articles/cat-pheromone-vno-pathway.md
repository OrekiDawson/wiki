# Cat Pheromone / VNO Pathway 背景

**来源**: Wikipedia + PetMD + Ceva Connect + ScienceDirect (Belluscio 1999)

## 核心知识

### 犁鼻器（VNO / Jacobson's Organ）

- 位于口腔顶部硬腭上方的成对感觉器官
- 猫通过 flehmen response（咧嘴反应）让 F3 进入 VNO
- VNO 神经元把信号送到**副嗅球（AOB）**，不经过主嗅球
- 从 AOB 直接进入内侧杏仁核 → 下丘脑 → 行为输出

### Flehmen 反应

> 猫闻到 F3 时会做"咧嘴"动作（开口，唇部卷起，露出上犬齿），将气味分子吸到 VNO 入口。这是判断猫在分析"安全信号"还是普通气味的标志。

### 为什么人类闻不到 F3

- 人类 VNO 在胎儿期有，出生后退化（仅留软骨痕迹）
- 人类 VNO 受体基因是**伪基因**（pseudogene）
- 人类没有副嗅球（AOB）
