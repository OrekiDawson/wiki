# 精油 / 香薰 / 扩香对猫的毒性（综述笔记）

> 调研日期：2026-06-30  
> 目的：摆清精油 / 香薰 / 扩香 / 蜡烛 / 藤条瓶在猫面前的硬科学依据。  
> 资料等级：ASPCA / VCA / 兽医学期刊 > 商家宣传。

## 1. 硬科学依据

### 1.1 猫缺 UGT 酶

- 猫**缺** UDP-glucuronosyltransferase（**UGT**）—— 这是其他哺乳动物用来代谢**酚类（phenols）** 和**单萜烯（monoterpenes）** 的关键肝酶
- 缺 UGT → 精油里的酚类 + 单萜烯在猫体内**积累**，**不能**正常排泄
- 即使浓度很低，**长期暴露**也会出现肝毒 / 神经毒

### 1.2 吸入 vs 皮肤 vs 口服

- **吸入**（扩香 / 蜡烛 / 藤条瓶）：酚类 + 单萜烯 → 肺泡 → 血 → 肝（不能代谢）→ **积累**
- **皮肤**：直接透皮吸收（猫舔毛会把精油从毛皮上摄入）
- **口服**：猫自我梳理时摄入（最危险）
- 吸入"少量"**不**等于"无风险"——猫体型小、UGT 缺失，**慢性积累**是真问题

## 2. ASPCA 列出的"对猫高风险"精油

| 精油 | 主要毒成分 | 风险等级 |
|---|---|---|
| **冬青油**（wintergreen） | 水杨酸甲酯 | **极高** |
| **甜桦油**（sweet birch） | 水杨酸甲酯 | **极高** |
| **柑橘类**（orange / lemon / grapefruit / lime） | 柠檬烯 + 芳樟醇 | **高** |
| **松科**（pine / spruce / fir） | 松萜 | **高** |
| **依兰**（ylang ylang） | 异戊烯基酯 | **高** |
| **薄荷**（peppermint） | 薄荷醇 + 薄荷酮 | **高** |
| **肉桂**（cinnamon） | 肉桂醛 | **高** |
| **薄荷酮 / 除蚤薄荷**（pennyroyal） | 胡薄荷酮 | **极高**（肝毒） |
| **丁香**（clove） | 丁香酚 | **高** |
| **桉树**（eucalyptus） | 桉油精 | **高** |
| **茶树**（tea tree / melaleuca） | 萜品烯-4-醇 | **极高**（哪怕少量） |
| **薰衣草**（lavender） | 芳樟醇 + 乙酸芳樟酯 | **中-高** |
| **广藿香**（patchouli） | 广藿香醇 | **中** |
| **肉豆蔻**（nutmeg） | 肉豆蔻醚 | **中-高**（神经毒） |

## 3. 临床表现

- **急性**（高剂量）：流涎 / 呕吐 / 共济失调 / 震颤 / 嗜睡 / 呼吸困难
- **慢性**（低剂量长期）：肝酶↑ / 黄疸 / 体重↓ / 行为变化 / 癫痫样发作
- 茶树（melaleuca）：**外用 0.1-1 mL 100% 油** 即可引起猫中毒（ASPCA APCC 数据）
- **百利甜**（pennyroyal）：已报告猫致死案例

## 4. 扩香器 / 蜡烛 / 藤条瓶的具体风险

### 4.1 超声波扩香

- 雾化精油 → 猫持续吸入
- **不**推荐有猫家庭使用
- 如果**必**要用：通风良好房间 + 猫**不**在该房间 + **浓度低于厂家推荐** + 限时

### 4.2 蜡烛

- 燃烧精油蜡烛 → 烟雾含酚类 + 一氧化碳
- **不**推荐

### 4.3 藤条瓶（reed diffuser）

- 缓慢挥发 → 持续低浓度暴露
- **不**推荐有猫家庭

### 4.4 干花 / 干草 / 干薄荷

- 干薄荷在猫面前**风险较低**（挥发量极小），但**不**让猫**吃**到

## 5. 对小桔宝（1kg 2 月幼猫）的建议

- **绝对不用** 任何形式的扩香 / 蜡烛 / 藤条瓶
- **不**用薰衣草"安神"枕头 / 干花 / 干薄荷 / 百里香等
- **不**在猫面前**直接**用任何精油外用
- **不**在猫能进入的房间放精油瓶
- **想要香味** → 用**对猫无毒**的产品（**不**含精油），或**通风好的非猫房间**少量用，**门关**住
- **手接触过精油** → **彻底洗手**再摸小桔宝

## 6. 误食 / 误吸应急

- 看到猫流涎 / 呕吐 / 共济失调 / 嗜睡 / 呼吸异常 / 抽搐 → **立刻**联系兽医 / 急诊
- **不**催吐（精油吸入性肺炎风险）
- **带产品包装**给兽医看

## 7. 关键认知

- 猫 + 精油 = **不是"安全浓度"问题**，是**缺 UGT = 慢性积累**问题
- "少量无毒"在**人**语境里**不**适用于**猫**
- "狗能用"也**不**等于"猫能用"（犬 UGT 也比猫强，但比人差）
