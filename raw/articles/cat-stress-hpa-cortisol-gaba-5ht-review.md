# 猫压力神经内分泌与安抚手段卡位（综述笔记）

> 调研日期：2026-06-30  
> 目的：把猫的"应激"拆成 HPA 轴 / 皮质醇 / 杏仁核 / GABA / 5-HT / 肠脑轴 6 块，看清 **F3 / α-酪蛋白 / L-茶氨酸 / BL999 / 处方粮** 各自卡哪一环。  
> 资料等级：PMC 综述 > 兽医学期刊 RCT > 厂商研究 > 商家宣传。

## 1. HPA 轴（应激通路总开关）

- **HPA = Hypothalamic-Pituitary-Adrenal**（下丘脑 - 垂体 - 肾上腺）
- 路径：应激源 → **下丘脑**释放 CRH → **垂体**释放 ACTH → **肾上腺皮质**释放 **皮质醇** → 全身应激反应
- 猫的**急性应激** = HPA 短时激活，应激源消失后回到 baseline（10-30 分钟内）
- 猫的**慢性应激** = HPA 持续激活，皮质醇基线↑，长期**抑制免疫**+**膀胱上皮损伤**（跟 FIC 发病机制相关）
- **关键**：F3 不是卡 HPA 轴——它是**在应激源被感知之前**就告诉猫"这里安全"，减少 HPA 启动

## 2. 皮质醇（cortisol）

- 猫应激的**金标准生物标志物**——研究里常用**粪便皮质醇**（fecal cortisol metabolites, FCM）做非侵入式测量
- 急性应激 → 血浆皮质醇 5-10 分钟内↑ 2-5 倍
- 慢性应激 → 基础 FCM 持续偏高
- **F3 与皮质醇**：Vitale 2018 综述提到 F3 跟"降低应激相关的皮质醇"有关联；但**单看皮质醇改善**的 RCT 数据较少——多数研究用"行为评分"作主终点，皮质醇作次终点

## 3. 杏仁核（amygdala）—— 警觉中心

- 接收**嗅觉信息**（含 VNO 信息素信号）和**皮层恐惧信号**，决定"战斗 / 逃跑 / 僵住"
- F3 → VNO → 杏仁核 → 下丘脑路径（详见 [[concepts/vomeronasal-organ-pheromone-pathway]]）
- **慢性应激** = 杏仁核基线警觉度持续↑，导致 HPA 持续激活

## 4. GABA（γ-氨基丁酸）

- **GABA_A 受体**：主要的"抑制性"受体，激活 → 神经元不放电 → 抗焦虑
- **GABA_B 受体**：突触前抑制，调节神经递质释放
- 苯二氮卓类（地西泮等）= 经典 GABA_A 激动剂（**人**用药，**猫慎用**——肝代谢差异大）
- **α-酪蛋白水解物**（α-casozepine，Zylkene 活性成分）= GABA_B 部分激动剂，**比苯二氮卓温和**，猫可用

## 5. 5-HT（血清素，serotonin）

- 抗焦虑 / 抗冲动 / 调节情绪
- 猫的 5-HT1A 受体激动剂 = 抗焦虑药（如丁螺环酮 buspirone，兽医开方）
- **L-茶氨酸**（Anxitane / 绿茶里）= 增加 GABA / 多巴胺 / 5-HT 释放
- **BL999 长双歧杆菌**（Calming Care）= 通过**肠脑轴**影响 5-HT 合成

## 6. 肠脑轴（gut-brain axis）

- 猫的肠道菌群 ≈ 100 万亿细菌，**菌群-肠-脑**双向通讯
- 应激 → 菌群多样性↓
- **BL999 / Calming Care**（Purina）= 长双歧杆菌 BL999，RCT 数据见 [[concepts/f3-vs-probiotics-vs-amino-acids]]

## 7. 各安抚手段的卡位

| 手段 | 作用层 | 卡位 |
|---|---|---|
| **F3**（Feliway Classic） | 嗅觉 → VNO → 杏仁核 → HPA | **上游信号** |
| **FAP**（Feliway Friends） | 同 F3，但作用猫-猫关系 | 上游信号 |
| **α-酪蛋白**（Zylkene） | GABA_B 激动 | **神经递质层** |
| **L-茶氨酸**（Anxitane） | GABA / 5-HT / 多巴胺 | 神经递质层 |
| **BL999 益生菌**（Calming Care） | 肠脑轴 → 5-HT | **菌群层** |
| **色氨酸**（处方粮 / 营养补剂） | 5-HT 前体 | 神经递质前体 |
| **处方粮**（Royal Canin Calm） | α-酪蛋白 + L-色氨酸 | **营养+神经递质组合** |
| **行为治疗** | 认知 / 环境 / 习惯 | **行为层** |
| **环境管理**（躲藏点/多猫资源/抓板） | 减少应激源 | **物理环境层** |

## 8. 关键认知

- **F3 ≠ 镇定剂**——它不改 GABA/5-HT，它改"环境信号"
- **组合可以叠加**（不同层互不冲突）：F3 + 处方粮 + 益生菌 + 环境管理 = **多模态**
- **不能叠加**的：α-酪蛋白 + 苯二氮卓（同卡 GABA 系统，可能镇静过度）
- **对幼猫慎用**：L-茶氨酸 / 益生菌 / 处方粮**在 1-2 月幼猫的 RCT 几乎为零**——大多数是成猫或应激诱导试验
