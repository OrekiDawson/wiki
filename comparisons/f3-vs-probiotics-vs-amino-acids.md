# F3 vs α-酪蛋白 / L-茶氨酸 / BL999 / Calm 粮（横向对比）

> 这是 [[comparisons/f3-by-scenario]] 的**纵向**扩展——同一问题（"猫焦虑 / 应激")下的不同干预手段横评。

## 一句话

> **F3** 卡上游"环境信号"层（VNO→杏仁核→HPA）；**α-酪蛋白** / **L-茶氨酸** 卡中游 GABA / 5-HT 神经递质；**BL999 益生菌** 卡下游"肠脑轴 → 5-HT"；**Calm 粮** 是**组合**（α-酪蛋白 + L-色氨酸）。**F3 跟其它不冲突，可叠加为多模态**。

## 1. 卡位对照

| 手段 | 作用层 | 卡位 | 起效时间 | 持续时间 |
|---|---|---|---|---|
| **F3 Classic** | 嗅觉 → VNO → 杏仁核 → HPA | **上游** | 7 天 | 30 天/瓶 |
| **FAP Friends** | 同 F3，但作用猫-猫 | 上游 | 7-14 天 | 30 天/瓶 |
| **α-酪蛋白**（Zylkene） | GABA_B 激动 | **神经递质** | 14-28 天 | 持续服用 |
| **L-茶氨酸**（Anxitane） | GABA / 5-HT / DA | 神经递质 | 15-30 天 | 持续服用 |
| **BL999 益生菌**（Calming Care） | 肠脑轴 → 5-HT | **菌群** | 28+ 天 | 持续服用 |
| **Royal Canin Calm 粮** | α-酪蛋白 + L-色氨酸 | **组合** | 28+ 天 | 持续食用 |

## 2. 证据等级

| 手段 | 证据等级 | 关键研究 | 样本数 |
|---|---|---|---|
| F3 Classic | **强** | PLOS One 2023 抓挠 RCT / Mills 2001 喷尿 / Crump 2023 综述 | 多 RCT 大样本 |
| F3 急性应激 | **中等** | Crump 2023 综述 5/4 部分有效 | 5 RCT |
| α-酪蛋白（Zylkene） | **中等** | Beata 2007 *J Vet Behav* | 34 只猫 open-label |
| L-茶氨酸（Anxitane） | **中等-较弱** | Rème 2018 *Irish Vet J* PMC6178259 | 33 只猫 open-label（无安慰剂） |
| BL999 益生菌 | **较弱** | 厂商研究（缺透明 RCT） | — |
| Royal Canin Calm 粮 | **中等** | Beata 2016 PMID 27677831 | 较小样本 |
| 处方药（丁螺环酮等） | **强** | 兽医开方 | — |

## 3. 副作用

| 手段 | 副作用 | 严重程度 |
|---|---|---|
| F3 Classic | 几乎无 | 极低（少数人对载体敏感） |
| α-酪蛋白 | 偶有软便 | 极低 |
| L-茶氨酸 | 几乎无 | 极低 |
| BL999 益生菌 | 偶有排气 / 软便 | 极低 |
| Calm 粮 | 配方特殊，**不**当主粮长期 | 中（须按兽医） |
| 处方药（丁螺环酮） | 嗜睡 / 胃肠反应 | 中-高（**需兽医**） |

## 4. 对 1-2 月幼猫的适用性

- **F3** = **有**幼猫数据（Vitale 2018 综述 + AAFP 适应期建议）✅
- **α-酪蛋白** / **L-茶氨酸** = **无** 1-2 月幼猫 RCT（Beata 2007 / Rème 2018 都没 1-2 月）⚠️
- **BL999 益生菌** = **无**幼猫数据，**几乎无 RCT 透明度** ⚠️
- **Calm 粮** = **无** 1-2 月幼猫数据 + **不**是幼猫主粮 ⚠️

**结论**：1-2 月幼猫**最稳** = F3 + 环境管理（躲藏点 + 多猫资源 + 抓板），**不**冒险加安抚补剂。

## 6. 多模态叠加规则

**可叠加**（不同层互不冲突）：
- F3 + α-酪蛋白 + 益生菌 + 环境管理 ✅
- F3 + L-茶氨酸 + 环境管理 ✅
- F3 + 处方粮 ✅
- 行为治疗 + 任何药物 ✅

**不叠加**（同系统）：
- α-酪蛋白 + 苯二氮卓类（地西泮等）= GABA 系统双激动 → 镇静过度
- L-茶氨酸 + 5-HT1A 激动剂（丁螺环酮）= 5-HT 系统双激动 → 5-HT 综合征风险

**对幼猫（1-2 月）**：
- **只**用 F3 + 环境管理
- **不**加任何补剂（缺数据）
- **不**在"有点焦虑"时加，等**兽医评估**

## 7. 给小桔宝的当前方案

- **已经在用**：Feliway Classic 24h 散
- **Petkit N60/N50**：**暂时关净味**（柿单宁 = 多酚 = 缺 UGT 风险）
- **不**加：α-酪蛋白 / L-茶氨酸 / BL999 / Calm 粮
- **不**用：精油 / 扩香 / 蜡烛 / 藤条瓶
- **7/12 换 F3 瓶** + **6 盏灯观察**
