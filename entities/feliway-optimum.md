# Feliway Optimum

## 一句话

**Feliway Optimum = "FPhC（Feline Pheromone Complex）"专利配方**，包含 F3 + FAP + 多个新发现的安抚信号 — Ceva 用**猫 VR1 犁鼻器受体的 in silico 模型**开发。

## 关键参数

| 参数 | 值 |
|---|---|
| 活性成分 | FPhC（F3 + FAP + 新安抚信号专利） |
| 形态 | 扩散器（48ml / 瓶）/ 项圈（13% 浸渍缓释，28 天） |
| 起效 | 7 天内 |
| 价格 | 扩散器 ¥400-500 / 项圈 ¥200-300 |

## 关键 RCT（Endersby 2024）

**Endersby et al. (2024) Frontiers Vet Sci, PMC11694449**：
- 624 猫 / 459 户，28 天，Optimum 项圈 vs 硅胶对照
- 效力分析 491 猫

| 行为 | p 值 | 显著？ |
|---|---|---|
| 抓挠 | p < 0.01 | ✅ |
| 喷尿 | p < 0.05 | ✅ |
| 猫间冲突 | p < 0.01 | ✅ |
| 恐惧 | p = 0.063 | ❌ 趋势 |

- **约 2 倍的猫**在 Optimum 项圈组停止问题行为
- 不良事件：Optimum 24.7% / 对照 29.7%

## 关键创新

> "Developed using in silico binding modeling of feline VR1 pheromone receptor in vomeronasal organ"

Ceva 用**猫 VR1 犁鼻器受体的 in silico 模型**开发了新一代配方。这是 2024 年最新的"精准费洛蒙"研究方向。

## 适应症 vs Classic / Friends

| 场景 | 推荐 |
|---|---|
| 单猫喷尿/抓挠 | Classic（更便宜，证据更扎实） |
| 多猫冲突 | Friends（FAP 更专） |
| 多问题同时存在（喷尿+抓挠+猫间冲突） | **Optimum**（覆盖最广） |
| 恐惧（最弱项） | 都不强，p=0.063 趋势 |

## 资助方

Ceva 内部研发 + 资助 Endersby 2024（利益冲突），但样本量大（624 猫）让结果可信度尚可。

## 小桔宝

**暂不换 Optimum**。原因：
1. 单猫家庭 Classic 已经够了
2. Optimum 单成分效力不如专用款（F3 喷尿不如 Classic 强，FAP 多猫冲突不如 Friends 强）
3. 价格更贵（400 vs 280）

未来如果小桔宝出现 **多问题同时**（如喷尿 + 抓挠 + 陌生人恐惧）→ 评估换 Optimum。
