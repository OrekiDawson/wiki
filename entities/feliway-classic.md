# Feliway Classic

## 一句话

**Feliway Classic = F3 合成版的扩散器产品**，法国 Ceva 出品，用于减少猫喷尿、抓挠、新环境应激。

## 关键参数

| 参数 | 值 |
|---|---|
| 活性成分 | F3 费洛蒙 2%（油酸 68% + 壬二酸 8% + 庚二酸 9% + 棕榈酸 15%） |
| 载体 | 异构烷烃 |
| 容量 | 48ml / 瓶 |
| 持续 | 30 天 / 瓶 |
| 起效 | 7 天内看到 |
| 覆盖 | 700 平方英尺（约 65 m²） |
| 价格 | ¥280-350 / 套装（京东） |

## 适应症（证据强度）

- ✅ **喷尿（标记）**：强（Mills 2001 等多项 RCT）
- ✅ **抓家具**：强（[[raw/articles/feliway-classic-scratching-plos-2023]] 三盲 RCT p<0.0001）
- ⚠️ **急性应激**：中等（Crump 2023 综述 5 篇里 4 篇部分有效）
- ⚠️ **FIC**：较弱（样本小）
- ⚠️ **慢性焦虑整体安定**：较弱（多为厂商研究）

## 用法要点

- **24h 持续插电**（不间断散发）
- **距地面 20-30cm**，不要被家具挡住出风口
- **不要放在通风口下方**
- **不要放在鱼缸附近**
- **猫最常待的房间**，不要放在角落

## 副作用

- 极少数人对载体（异构烷烃）敏感：咽喉不适 / 头疼 / 皮肤反应
- **鱼缸附近禁用**（异构烷烃对鱼鳃有毒）
- **对猫几乎无副作用**：不进入血液，不被代谢，species-specific（只对猫有效）

## 小桔宝当前使用

✅ 6/12 开始 24h 散，6/29 已用 18 天
- 7/12 换瓶（48ml 用完）
- 暂不换 Optimum / Friends
