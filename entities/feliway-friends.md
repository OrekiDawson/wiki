# Feliway Friends

## 一句话

**Feliway Friends = FAP（Cat Appeasing Pheromone，猫安抚费洛蒙）的扩散器产品**，法国 Ceva 出品，**用于多猫家庭减少冲突**。注意：FAP **不是** F3。

## FAP 与 F3 的区别

| 维度 | F3 (Classic) | FAP (Friends) |
|---|---|---|
| 分泌部位 | 脸颊/唇周腺 | 母猫乳腺皮脂腺 |
| 分泌时间 | 整个成年期 | 产后 3-4 天至断奶后 2-5 天 |
| 主功能 | 标记"环境安全" | 标记"我们是一伙的/别打架" |
| 适用 | 单猫 / 多猫都适用 | **主要给多猫家庭** |

详见 [[comparisons/f3-vs-fap-vs-optimum]]

## 关键参数

| 参数 | 值 |
|---|---|
| 活性成分 | FAP 2% + 异构烷烃 48ml |
| 容量 | 48ml / 瓶 |
| 持续 | 30 天 / 瓶 |
| 起效 | 7-14 天 |
| 价格 | ¥300-400 / 套装 |

## 证据强度

**中等**（p=0.06 趋势）

DePorter 2018（PMC6435919）— 45 个多猫家庭，FAP n=20 / 安慰剂 n=25：
- OFSIS 攻击评分两组都下降（时间效应 p=0.0001）
- FAP 组略优（p=0.06）
- 主人满意度：FAP 84.2% vs 安慰剂 64%（p=0.14，趋势）
- 资助方是 Ceva（利益冲突）

## 适用场景

- 多猫家庭出现打架 / 资源争抢 / 猫间回避
- 介绍新猫时合并使用（让"我们是一伙的"信号铺底）
- 已绝育猫的慢性攻击行为

## 不适用场景

- 单猫家庭（用 Classic 即可）
- 资源竞争引起的攻击（资源要分开，不靠费洛蒙）

## 小桔宝

**当前不需要**（单猫）。如果未来养第二只猫 → 立刻换 Friends + Classic 同时用。
