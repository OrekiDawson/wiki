# Ceva Santé Animale

## 一句话

**法国动物保健公司**，Feliway 系列的制造商，1996 年公开猫 F3 费洛蒙合成专利（US5709863A）的持有者。

## 关键事实

| 项 | 值 |
|---|---|
| 总部 | Libourne, France |
| 业务 | 动物保健（疫苗、费洛蒙、药品） |
| Feliway 业务 | 占猫行为产品线主体 |
| 专利 | US5709863A（1996）— F3 配方 |
| 内部研发 | 用 VR1 犁鼻器受体的 in silico 模型开发 Optimum |

## 主要产品

- **Feliway Classic**（F3）— 见 [[entities/feliway-classic]]
- **Feliway Friends**（FAP）— 见 [[entities/feliway-friends]]
- **Feliway Optimum**（FPhC 专利）— 见 [[entities/feliway-optimum]]
- **Feliway Help 7 天装** — 一次性应激
- **Feliway Spray** — 外出/就诊

## 利益冲突注意

Ceva 资助 / 合作了多篇 Feliway 产品的 RCT：
- Endersby 2024（PMC11694449）— Optimum 项圈
- DePorter 2018（PMC6435919）— Friends
- Crump 2023 综述里的部分 RCT

研究结果**质量仍然可信**（多数 PLOS One / Frontiers 级别），但**读 RCT 时要看资助方**。独立验证仍然较少。
