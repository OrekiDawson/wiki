# 小桔宝味道安全图（精油 / 香薰 / 扩香 / Petkit N60）

> 给小桔宝**家里**的"味道"做一张安全地图。

## 一句话

> 猫**缺 UGT**（UDP-glucuronosyltransferase），**任何**精油 / 扩香 / 蜡烛 / 藤条瓶在猫面前 = **硬风险**。**小桔宝家额外注意**：智能猫厕所里的 **Petkit N60/N50 含"柿果提取物" = 多酚** → 也属"酚类代谢"风险，**先**关净味。

## 1. 绝对不用

- 任何**精油**：冬青 / 甜桦 / 柑橘 / 松科 / 依兰 / 薄荷 / 肉桂 / 除蚤薄荷 / 丁香 / 桉树 / **茶树** / 薰衣草 / 广藿香 / 肉豆蔻
- 任何**扩香**：超声波 / 蜡烛 / 藤条瓶
- 任何**含精油的"猫用香薰"产品**——**不**存在"对猫安全"的精油产品
- 任何**驱蚤项圈 / 滴剂**含精油（"天然"不等于安全）
- **小桔宝能进入的房间**任何形式

## 2. Petkit N60 / N50（小桔宝智能猫厕所里装）

- N60 成分：去离子水 + 结冷胶 + 增溶剂 + 复合氨基酸 + **柿果提取物** + 香精 + 1,2-己二醇
- N50 成分：皱波角叉菜 + 无机盐 + 增溶剂 + 复合氨基酸 + **柿果提取物** + 香精
- **柿单宁 = 多酚** → 猫**缺 UGT** → 代谢酚类差
- 密闭空间（猫厕所内部）+ 持续释放 + 猫**近距离**嗅闻 + **舔舐**风险
- **Oreki 6/30 校准**：小桔宝"不太适应"智能厕所 → **暂时关净味**（已记进 [[queries/f3-for-xiaojubao]]）
- 之后再开 → 看小桔宝是否有肝酶异常 / 行为变化

## 3. 临床症状（万一小桔宝误触 / 误食）

- **急性**：流涎 / 呕吐 / 共济失调 / 震颤 / 嗜睡 / 呼吸困难
- **慢性**：肝酶↑ / 黄疸 / 体重↓ / 行为变化 / 癫痫样发作
- 看到任一 → **立刻**联系兽医 / 急诊
- **不**催吐（精油吸入性肺炎风险）
- **带产品包装**给兽医看

## 4. 想要"香味"怎么办

- **不**用精油扩香
- **不**用香薰蜡烛 / 藤条瓶
- **可**：通风好的非猫房间少量用精油，**门关**住
- **可**：用**对猫无毒**的产品（**不**含精油），或**纯植物干花**（**不**让猫**吃**到）
- **不**在猫面前喷任何气味（除臭剂 / 香水 / 香体喷雾 / 衣物柔顺剂）

## 5. 应急联系人

- 兽医电话 / 急诊电话（24 小时）= **Oreki 维护一份**
- 误食 / 误吸 → 兽医 + **ASPCA APCC 热线**（美国，收费；中国 = 当地宠物急诊）

## 6. 关键认知

- 猫 + 精油 = **不是"安全浓度"问题**，是**缺 UGT = 慢性积累**问题
- "少量无毒"在**人**语境里**不**适用于**猫**
- "狗能用"也**不**等于"猫能用"
- Petkit N60 / N50 **不**是 F3 类费洛蒙，**是除臭剂**，**不**在 F3 地图里
