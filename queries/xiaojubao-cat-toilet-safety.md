# 小桔宝智能猫厕所安全（Petkit N60/N50 + 净味）

> 评估智能猫厕所里 Petkit N60/N50 净味除臭对 1kg / 2 月幼猫的**实际**风险。

## 一句话

> Petkit N60/N50 **含"柿果提取物" = 多酚**。猫**缺 UGT** → 代谢酚类差。**先**关净味（已记进 [[queries/f3-for-xiaojubao]]），风险降 0。之后再开 → 看小桔宝是否有肝酶异常 / 行为变化。

## 1. N60 / N50 真实成分（Petkit 官网）

| 产品 | 成分 |
|---|---|
| **N60** | 去离子水 + 结冷胶 + 增溶剂 + 复合氨基酸 + **柿果提取物** + 香精 + **1,2-己二醇** |
| **N50** | 皱波角叉菜 + 无机盐 + 增溶剂 + 复合氨基酸 + **柿果提取物** + 香精 |

**核心**：两者都含**柿果提取物 = 柿单宁 = 多酚**。

## 2. 多酚为什么对猫有风险

- 猫**缺** UDP-glucuronosyltransferase（**UGT**）—— 其他哺乳动物用来代谢**酚类（phenols）** 和**单萜烯（monoterpenes）** 的关键肝酶
- 缺 UGT → 多酚在猫体内**积累**，**不能**正常排泄
- 长期暴露 → 肝酶↑ / 黄疸 / 体重↓ / 行为变化

## 3. 智能猫厕所的特殊风险

- 密闭空间（猫厕所内部）+ 持续释放 + 猫**近距离**嗅闻 + **舔舐**风险
- 不是"扩散到空气"那种扩香，但**密闭空间 + 持续释放 + 猫嘴近** = 风险**集中**
- 1-2 月幼猫体重 1kg → **同剂量**比成猫**单位体重暴露量**高

## 4. 决策

- **当前**：智能厕所**关净味**（Oreki 6/30 校准）
- 关掉 → 暂停 N60 暴露 → 风险降 0
- 之后开净味 → 看小桔宝**实际**反应（食欲 / 体重 / 精神 / 大小便 / 行为）

## 5. 应急

- 看到任一**急性**症状（流涎 / 呕吐 / 共济失调 / 嗜睡 / 呼吸困难 / 抽搐）→ **立刻**联系兽医
- **不**催吐
- **带产品包装**给兽医看

## 6. 关键认知

- N60/N50 **不**是 F3 费洛蒙，**是除臭剂** → **不**在 F3 地图里
- "对狗安全"≠"对猫安全"（FurLab 兽医观点 2024）
- 1kg 幼猫 = **单位体重风险**比成猫高
- "先关净味"是**最稳**的一刀切
