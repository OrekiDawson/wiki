# 精油 / 香薰 / 扩香在猫面前的安全性

> 概念页：猫用精油 / 香薰 / 扩香 / 蜡烛 / 藤条瓶的风险图。

## 一句话

> 猫**缺** UGT 酶（UDP-glucuronosyltransferase），**不能**代谢酚类 + 单萜烯。**任何**形式的扩香 / 蜡烛 / 藤条瓶在小桔宝面前 = **硬风险**。**不**用就对了。

## 1. 硬科学依据

- 猫**缺** UDP-glucuronosyltransferase（UGT）—— 其他哺乳动物用来代谢**酚类（phenols）** 和**单萜烯（monoterpenes）** 的关键肝酶
- 即使浓度很低，**长期暴露**也会出现肝毒 / 神经毒
- "少量无毒"在**人**语境里**不**适用于**猫**

## 2. ASPCA 高风险精油

| 精油 | 主要毒成分 | 风险等级 |
|---|---|---|
| **冬青油** / **甜桦油** | 水杨酸甲酯 | **极高** |
| **柑橘类** | 柠檬烯 + 芳樟醇 | **高** |
| **松科** | 松萜 | **高** |
| **依兰** | 异戊烯基酯 | **高** |
| **薄荷** | 薄荷醇 + 薄荷酮 | **高** |
| **肉桂** | 肉桂醛 | **高** |
| **除蚤薄荷** | 胡薄荷酮 | **极高**（肝毒） |
| **丁香** | 丁香酚 | **高** |
| **桉树** | 桉油精 | **高** |
| **茶树** | 萜品烯-4-醇 | **极高**（哪怕少量） |
| **薰衣草** | 芳樟醇 + 乙酸芳樟酯 | **中-高** |
| **广藿香** | 广藿香醇 | **中** |
| **肉豆蔻** | 肉豆蔻醚 | **中-高**（神经毒） |

## 3. 扩香 / 蜡烛 / 藤条瓶

- 超声波扩香：雾化 → 持续吸入 → **不**推荐
- 蜡烛：烟雾含酚类 + CO → **不**推荐
- 藤条瓶：缓慢挥发 → 持续低浓度 → **不**推荐
- 干花 / 干薄荷：风险较低（挥发量极小），但**不**让猫**吃**到

## 4. 临床症状

- **急性**：流涎 / 呕吐 / 共济失调 / 震颤 / 嗜睡 / 呼吸困难
- **慢性**：肝酶↑ / 黄疸 / 体重↓ / 行为变化 / 癫痫样发作
- 茶树：外用 0.1-1 mL 100% 油即可中毒

## 5. 小桔宝规则

- **绝对不用** 任何形式的扩香 / 蜡烛 / 藤条瓶
- **不**用薰衣草"安神"枕头 / 干花 / 干薄荷
- **不**在猫面前**直接**用任何精油外用
- **不**在猫能进入的房间放精油瓶
- **想要香味** → 对猫无毒产品 / 通风好的非猫房间 / **门关**住
- **手接触过精油** → **彻底洗手**再摸小桔宝

## 6. 应急

- 流涎 / 呕吐 / 共济失调 / 嗜睡 / 呼吸异常 / 抽搐 → **立刻**联系兽医 / 急诊
- **不**催吐（精油吸入性肺炎风险）
- **带产品包装**给兽医看
