# 猫压力生理学

> 概念页：把猫的"应激"拆成 6 块，看清**F3 跟其它安抚手段各自卡哪一环**。

## 一句话

> 猫的应激 = HPA 轴 + 杏仁核 + 神经递质（GABA/5-HT）+ 肠脑轴 4 层联动。**F3 卡上游"环境信号"层**，Zylkene / Anxitane 卡中游"神经递质"层，BL999 益生菌卡"肠脑轴"层。

## 1. HPA 轴

- 全称：Hypothalamic-Pituitary-Adrenal（下丘脑-垂体-肾上腺）
- 路径：应激源 → CRH → ACTH → **皮质醇** → 全身反应
- 急性 = 10-30 分钟回到 baseline
- 慢性 = 持续偏高 → 免疫↓、膀胱上皮损伤（FIC 机制）

## 2. 皮质醇

- 应激的**金标准生物标志物**
- 急性：血浆皮质醇 5-10 分钟↑ 2-5 倍
- 慢性：粪便皮质醇（FCM）持续偏高
- F3 与皮质醇：行为评分改善 + 皮质醇次终点改善的研究有，但**单看皮质醇**的 RCT 不多

## 3. 杏仁核

- 警觉中心，接收嗅觉（含 VNO 信息素信号）+ 皮层恐惧信号
- F3 → VNO → 杏仁核 → HPA 路径（详见 [[concepts/vomeronasal-organ-pheromone-pathway]]）
- 慢性应激 = 杏仁核基线警觉度持续↑ → HPA 持续激活

## 4. GABA（γ-氨基丁酸）

- 抑制性神经递质
- GABA_A：苯二氮卓（地西泮）位点——**人**用药，**猫慎用**
- GABA_B：α-酪蛋白（Zylkene 活性成分）= 部分激动剂

## 5. 5-HT（血清素）

- 抗焦虑 / 抗冲动 / 调节情绪
- L-茶氨酸（Anxitane）= 增加 5-HT 释放
- BL999 益生菌 = 通过肠脑轴影响 5-HT 合成

## 6. 肠脑轴

- 菌群-肠-脑 双向通讯
- 应激 → 菌群多样性↓
- BL999 / Calming Care（Purina）= 长双歧杆菌 BL999

## 7. 各安抚手段的卡位

| 手段 | 作用层 |
|---|---|
| F3（Feliway Classic） | 上游信号（VNO → 杏仁核 → HPA） |
| FAP（Feliway Friends） | 上游信号（猫-猫关系） |
| α-酪蛋白（Zylkene） | GABA_B 神经递质 |
| L-茶氨酸（Anxitane） | GABA / 5-HT / 多巴胺 |
| BL999 益生菌（Calming Care） | 肠脑轴 → 5-HT |
| L-色氨酸（处方粮） | 5-HT 前体 |
| 处方粮（Royal Canin Calm） | α-酪蛋白 + L-色氨酸组合 |
| 行为治疗 | 行为层 |
| 环境管理 | 物理环境层 |

## 8. 关键认知

- F3 ≠ 镇定剂，不改 GABA/5-HT，改"环境信号"
- 组合可叠加：F3 + 处方粮 + 益生菌 + 环境管理 = 多模态
- 对**幼猫**（1-2 月）RCT 几乎为零：L-茶氨酸 / 益生菌 / 处方粮的成猫数据不能直接套到小桔宝身上
