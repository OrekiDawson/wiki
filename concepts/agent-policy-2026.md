# 智能体规范应用与创新发展实施意见（2026）

中国首部专门针对 AI Agent（智能体）的系统性政策文件，国家网信办、发改委、工信部三部门于 **2026年5月8日** 联合正式印发。

## 基本信息

| 项目 | 内容 |
|------|------|
| **发布机构** | 国家互联网信息办公室 + 国家发改委 + 工信部 |
| **发布时间** | 2026年5月8日 |
| **文件性质** | 正式文件（非征求意见稿） |
| **上位依据** | 国务院《关于深入实施"人工智能+"行动的意见》（2025年8月） |
| **关联法规** | 《生成式人工智能服务管理暂行办法》（2023）、《个人信息保护法》、《数据安全法》 |

## 核心框架

### 四大基本原则
1. **安全可控** — 贯穿研发、部署、应用全过程
2. **规范有序** — 分类分级治理，先易后难
3. **创新驱动** — 理论、技术、工程创新联动
4. **应用牵引** — 19 大应用场景，以示范促落地

### 关键治理措施

**分类分级治理：**
- **高风险领域**（敏感行业/重点场景）：备案、检测、产品召回
- **低风险领域**（生活娱乐/日常办公）：合规自测、行业自律

**智能体权限边界：**
- 用户本人决策 vs 用户授权决策 vs 智能体自主决策
- **用户拥有知情权和最终决策权**，智能体不得越权执行

**安全要求：**
- 内生安全（数据安全、隐私保护、攻击检测、权限管理）
- 供应链安全（模型接入、API调用、扩展工具管控）
- 行为可追溯（区块链存证）
- 防沉迷（防范未成年人/老年人情感依赖）

## 19 大应用场景

| 领域 | 场景 |
|------|------|
| 科学研究 | 科研探索、研发辅助 |
| 产业发展 | 智能制造、能源资源、交通运输、农业生产、金融服务 |
| 提振消费 | 终端应用、文化旅游、商业服务 |
| 民生福祉 | **教育教学**、医疗健康、人力资源、信息服务 |
| 社会治理 | 政务服务、司法服务、公共安全、城市治理、招标投标 |

**软件开发 Agent** 被明确鼓励——需求分析→架构→代码生成→测试全流程。

## AIP 标准体系

文件中强推 [[aip-protocol|AIP（智能体互联协议）]]，这是中国自主制定的国家级 Agent 互联标准，7 项国标涵盖总体架构、身份码、身份管理、Agent 描述、发现、交互、工具调用。详见 [[aip-protocol]]。

## 与 [[ai-agent-governance-eu-us-cn|国际对比]] 的定位

中国方案介于 EU AI Act 和美国 AI Executive Order 之间：
- 借鉴 EU 的**风险分级**思路
- 保留美国的**行业自律**特点
- 独创 AIP 标准、智能互联网、19 大场景等**产业促进**措施
- 核心特色：**"发展与安全并重"**

## 对小呦/Hermes 生态的影响

1. **AIP 协议潜在对接** — 如果 AIP 成为国内 Agent 互通事实标准，Hermes 的 MCP 工具链可能需要考虑与 AIP 的身份认证层配合
2. **合规身份码** — 未来 Agent 可能需要注册平台和数字身份，小呦作为运行在 Hermes 上的 Agent 需要关注这一趋势
3. **低风险豁免利好** — 生活娱乐/日常办公类 Agent 仍属行业自律范畴，短期内 Hermes 生态不受直接影响
4. **软件开发 Agent 鼓励方向** — 文件明确鼓励软件工程 Agent，与 Oreki 目前用的小呦+Claude Code 方向一致
