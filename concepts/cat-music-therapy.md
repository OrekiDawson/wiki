# 猫音乐疗法

> 概念页：猫用"猫音乐"是什么、怎么用、能不能跟 F3 叠加。

## 一句话

> 猫音乐 = 200-260Hz 滑动音 + 呼噜声节奏 + 慢速重复。Teie 2015 专辑有单 RCT 证据，慢速古典多项研究一致。**不**替代 F3 / 兽医，可**叠加**为多模态。

## 1. Teie 2015 *Music for Cats*

- 创作者：David Teie（马里兰大学音乐理论家 / 前 National Symphony 大提琴手）
- 设计：滑音 200-260Hz + 呼噜声节奏 25Hz + 哺乳期吮吸节奏
- 证据：Snowdon & Savage 2015 UW-Madison 47 只猫，猫音乐组蹭/揉/呼噜显著多
- 限制：单中心、小样本、行为评分（主观）

## 2. 慢速古典

- Kogan 2012 / Bowman 2015 / PMC10814571 2024：60-80 BPM 慢速古典 → 休息时间↑、应激行为↓
- 快节奏/摇滚/金属 → 应激行为↑
- 推荐：Spotify "Relax My Cat" / "Cat Music" 类

## 3. 呼噜声合成

- 25-50Hz 呼噜声
- 理论：促进骨密度 / 软组织修复（purr therapy 假说）
- **无 RCT**，纯理论

## 4. 雷暴 / 烟花恐惧

- 古典 + F3 = 多模态比单一好
- 但证据**弱-中等**

## 5. 给小桔宝的应用

| 场景 | 是否用 | 怎么做 |
|---|---|---|
| 白天独处 | ✅ | 慢速古典 + Teie 专辑循环 |
| 就诊/运输 | ❌（猫包） ✅（车里） | 猫包不放，车里小声 |
| 陌生访客 | ✅ | 调小音量 + 躲藏点 |
| 手术/急救 | ❌ | 不指望音乐 |

## 6. 跟 F3 的搭配

- F3 卡"环境信号"层
- 猫音乐卡"听觉环境"层
- **不冲突**，可叠加
