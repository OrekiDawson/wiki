# 小桔宝家用品产品地图

> 概念页：把"小桔宝家里已经买的 + 可能买的"所有安抚 / 除味 / 营养产品按"对猫是否安全 + 证据等级"两维评估。

## 一句话

> **F3 Classic** = 在用，证据强。**Petkit N60/N50** = **多酚风险**，**先**关净味。**α-酪蛋白 / L-茶氨酸 / BL999 / Calm 粮** = **不**加（1-2 月幼猫 RCT = 0）。**国产仿制费洛蒙** = **不**买（几乎无证据）。**精油 / 扩香 / 蜡烛 / 藤条瓶** = **绝对不用**（酚类硬风险）。

## 1. 家中现有产品

### Feliway Classic（F3 扩散器）
- 24h 散，48ml 30 天
- 证据强（PLOS One 2023 / Mills 2001 / Crump 2023）
- 详见 [[concepts/f3-pheromone]]

### Petkit N60 / N50（智能猫厕所里装）
- N60：去离子水 + 结冷胶 + 增溶剂 + 复合氨基酸 + **柿果提取物** + 香精 + 1,2-己二醇
- N50：皱波角叉菜 + 无机盐 + 增溶剂 + 复合氨基酸 + **柿果提取物** + 香精
- **柿单宁 = 多酚** → 猫**缺 UGT** → 代谢酚类差
- **暂时关净味**（Oreki 6/30 校准）
- 详见 [[queries/xiaojubao-cat-toilet-safety]]

## 2. 可能买的产品

| 产品 | 是否买/用 | 关键风险 | 证据等级 |
|---|---|---|---|
| α-酪蛋白（Zylkene） | ❌ 不加 | 幼猫 RCT 缺 | 中等（Beata 2007） |
| L-茶氨酸（Anxitane） | ❌ 不加 | 幼猫 RCT 缺 | 中等（Rème 2018） |
| BL999 益生菌（Calming Care） | ❌ 不加 | 幼猫 RCT 缺 | 较弱（厂商研究） |
| Royal Canin Calm 粮 | ❌ 不换 | 幼猫 RCT 缺 + 配方特殊 | 中等（Beata 2016） |
| 国产仿制费洛蒙 | ❌ 不买 | 几乎无证据 | 极弱 |
| 精油 / 扩香 / 蜡烛 / 藤条瓶 | ❌ 绝对不用 | 酚类 / 单萜烯 | 强（ASPCA 警示） |

## 3. 决策框架

按"对猫是否安全 + 证据等级"两维：

| 维度 | 评分 |
|---|---|
| **对猫安全** | 1（高风险）→ 5（极低风险） |
| **证据等级** | 1（极弱）→ 5（强） |

- **F3 Classic**：安全 5 + 证据 5 → ✅ 用
- **Petkit N60/N50**：安全 2（多酚风险）→ 关净味
- **α-酪蛋白 / L-茶氨酸**：安全 4 + 证据 3 + 幼猫缺数据 → ❌ 不加
- **BL999**：安全 4 + 证据 2 + 幼猫缺数据 → ❌ 不加
- **Calm 粮**：安全 3 + 证据 3 + 幼猫缺数据 + 配方特殊 → ❌ 不换
- **国产仿制**：安全 ? + 证据 1 → ❌ 不买
- **精油 / 扩香**：安全 1 + 证据 5（ASPCA 警示）→ ❌ 不用

## 4. 关键认知

- **F3 + 不刺激 + 环境管理** = 当前对小桔宝**最稳**的方案
- **6 盏灯 3 颗星持续 1 周+** → 找兽医评估，**不**自己加补剂
- **Petkit N60/N50 是除臭剂 ≠ F3 费洛蒙**，**不**在 F3 地图里
- **多酚类对小桔宝有潜在风险**（缺 UGT），**先**关净味
- "**对狗安全"**≠"对猫安全"
