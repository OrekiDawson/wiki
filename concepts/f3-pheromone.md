# F3（Feline Facial Pheromone Fraction 3）

## 一句话定义

**F3 = 猫脸颊 / 唇周腺体分泌的"环境安抚"信号**，猫通过摩擦物件把它留在环境中。商业合成版是 **[[entities/feliway-classic]]**。

## 1. 化学配方

来自 Ceva 1996 年专利 US5709863A（见 [[raw/articles/f3-pheromone-vitale-2018-pmc11343345]]）：

| 成分 | 比例 |
|---|---|
| 油酸（Oleic acid） | 68% |
| 壬二酸（Azelaic acid） | 8% |
| 庚二酸（Pimelic acid） | 9% |
| 棕榈酸（Palmitic acid） | 15% |

**物理形态**：油状液体，溶于异构烷烃（载体）；加热 ~60°C 雾化扩散。

## 2. 大脑受体路径

详见 [[concepts/vomeronasal-organ-pheromone-pathway]]：

```
F3 分子 → 猫脸摩擦 / 物品接触 → VNO（犁鼻器）入口
    ↓ flehmen 反应（咧嘴）
VNO 感觉神经元 → GPCR (Giα2 / Goα)
    ↓
副嗅球 (AOB)
    ↓
内侧杏仁核 → 下丘脑（HPA 轴）
    ↓
行为输出：标记"这里安全" / 减少喷尿 / 减少抓挠
```

**关键点**：F3 绕过主嗅皮层，直接进入边缘系统 — 所以是"安全信号"不是"香味"。

## 3. 完整猫费洛蒙家族（Vitale 2018）

| 简写 | 功能 | 商业版 |
|---|---|---|
| F1 | 未知 | 无 |
| F2 | 性行为标记 | 无 |
| **F3** | **环境安抚** | ✅ Feliway Classic |
| F4 | 友好接触（allorubbing） | 无 |
| F5 | 未知 | 无 |
| **FAP** | 母猫安抚（多猫冲突） | ✅ Feliway Friends |
| FIS | 趾间（标记抓挠） | ✅ 商业版少用 |

## 4. 证据强度（一句话）

- 喷尿 / 抓挠：**强**
- 急性应激（就诊/运输）：**中等**（[[raw/articles/f3-acute-stress-crump-2023-ve-669]] 综述 5 篇里 4 篇部分有效）
- 慢性焦虑整体安定：**较弱**（多为厂商研究）

详见 [[concepts/f3-clinical-evidence]]

## 5. 一句话总结

**F3 不是镇定剂，是"安全信号"。**它通过犁鼻器告诉猫的脑子"这里安全"。对小桔宝这种应激型安全感不稳的猫最合适；对未绝育公猫的性标记、甲状腺亢进、慢性疼痛等无效。
